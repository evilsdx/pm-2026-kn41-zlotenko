## 1. Definition of Workflow

| Колонка | Умова входу | Умова виходу |
| --- | --- | --- |
| Backlog | Роботу визначено, але її ще не уточнено для старту. | Результат, критерії приймання, залежності та розмір на 1–2 дні зрозумілі; картка переходить у Ready. |
| Ready | Картка відповідає Definition of Ready, має ключ F-NNN і зрозумілий результат. | Є вільне місце за WIP-лімітом; робота фактично починається, і картка переходить у In progress. |
| In progress | Виконавець почав роботу над карткою. | Результат створено та виконано самоперевірку; картка переходить у Review. Якщо потрібні зміни після перевірки — повертається в In progress. |
| Review | Артефакт доступний для перевірки за критеріями приймання. | Перевірку пройдено й результат зафіксовано — Done; інакше картка повертається в In progress із конкретними зауваженнями. |
| Done | Критерії приймання виконано, результат або посилання на нього зафіксовано. | Кінцевий стан картки. |

## 6. Перший вимір

Розрахунок робиться після двох тижнів спостереження щонайменше за вісьмома завершеними картками. Cycle time — календарні дні від дати «У роботі з» до дати «Завершена».

| Показник | Значення |
| --- | :-: |
| Найкоротший cycle time, днів | 1 |
| Найдовший cycle time, днів | 4 |
| Середній cycle time, днів | 2,75 |
| Завершених карток у вимірі | 8 (F-001–F-008, без F-009, завершеної після вимірювального періоду) |

Найдовше картки чекали в `Backlog`: частина завдань ЛР5 і ЛР6 була створена на початку симуляції, але бралася в роботу пізніше за пріоритетом.
